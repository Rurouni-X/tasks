# Tasks API

Простой RESTful API сервис для управления списком задач (Task Manager), написанный на **Go** с использованием библиотеки **sqlx** и базы данных **PostgreSQL**.

## 🚀 Стек технологий

* **Язык**: Go (встроенный `net/http` для маршрутизации)
* **База данных**: PostgreSQL 15
* **Библиотеки**: 
  * `github.com/jmoiron/sqlx` — расширение для стандартного пакета `database/sql`.
  * `github.com/lib/pq` — драйвер для подключения к PostgreSQL.
* **Окружение**: Docker / Docker Compose

## 🛠️ Запуск проекта

### 1. Подготовка базы данных
Убедитесь, что у вас установлен Docker и Docker Compose. 

Перенесите ваш SQL-скрипт инициализации в файл `./sql/init.sql`. При первом запуске контейнера этот скрипт автоматически создаст таблицу `tasks` и наполнит её тестовыми данными.

Запустите контейнер с PostgreSQL:
```bash
docker compose up -d
```

*База данных будет доступна локально на порту `5433`.*

### 2. Запуск Go сервера
Вы можете настроить параметры подключения через переменные окружения, либо сервер использует настройки по умолчанию.

```bash
# Использование настроек по умолчанию (localhost:5433)
go run cmd/main.go

# Или с явным указанием переменных окружения:
export DATABASE_URL="postgres://taskuser:taskpass@localhost:5433/tasksdb?sslmode=disable"
export SERVER_PORT="8080"
go run cmd/main.go
```

## 🗺️ API Эндпоинты

### 1. Получить все задачи
* **URL**: `/tasks`
* **Метод**: `GET`
* **Описание**: Возвращает список всех задач, отсортированных по дате создания (сначала новые).

### 2. Создать задачу
* **URL**: `/tasks/create`
* **Метод**: `POST`
* **Тело запроса (JSON)**:
  ```json
  {
    "title": "Купить молоко",
    "description": "Зайти в магазин около дома",
    "completed": false
  }
  ```

### 3. Получить задачу по ID
* **URL**: `/tasks/{id}` (например, `/tasks/1`)
* **Метод**: `GET`

### 4. Обновить задачу
* **URL**: `/tasks/{id}` (например, `/tasks/1`)
* **Метод**: `PUT`
* **Описание**: Обновляет только переданные поля (частичное обновление).
* **Тело запроса (JSON)**:
  ```json
  {
    "title": "Купить молоко и хлеб",
    "completed": true
  }
  ```

### 5. Удалить задачу
* **URL**: `/tasks/{id}` (например, `/tasks/1`)
* **Метод**: `DELETE`

## 📝 Особенности реализации

* **Логирование**: Встроен Middleware, который логирует каждый входящий HTTP-запрос (метод, путь и адрес клиента) в консоль.
* **Валидация методов**: Доступ к эндпоинтам строго ограничен разрешенными HTTP-методами (в случае несоответствия возвращается статус `405 Method Not Allowed`).
* **Пул соединений**: Настройки базы данных жестко задают `MaxOpenConns (20)` и `MaxIdleConns (5)` для оптимизации производительности.
